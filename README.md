# Demographic Data Analyzer

A Python project that analyzes demographic data from the 1994 U.S. Census database using the **Pandas** library. This project was completed as part of the **freeCodeCamp Data Analysis with Python Certification**.

## Overview

The program loads census data from `adult.data.csv` and computes a variety of demographic statistics, including:

* Population count by race
* Average age of men
* Percentage of people with a Bachelor's degree
* Percentage of high-income earners among people with and without advanced education
* Minimum working hours per week
* Percentage of high-income earners among minimum-hour workers
* Country with the highest percentage of people earning more than $50K
* Most common occupation among high-income earners in India

## Technologies Used

* Python 3
* Pandas

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Cgaur-2006/demographic-data-analyzer-freecodecamp.git
cd demographic-data-analyzer-freecodecamp
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the project

```bash
python main.py
```

## Dataset

This project uses the **1994 U.S. Census Adult Dataset**, which contains demographic information such as age, education, occupation, race, working hours, native country, and salary.
